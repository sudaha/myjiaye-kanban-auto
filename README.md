# 央采电子询价 · 招投标商机看板

一台 24 小时开机的 Windows 机器上，自动抓取**中央政府采购网**「电子询价 · 需求公告」，
并提供手机 / 电脑都能访问的网页看板（公告列表 + 筛选 + 详情 + 询价通知书 PDF 下载）。

**无需登录央采**：列表与详情接口均免登录直接可取，程序每 30 分钟自动增量抓取新公告。

---

## 一、快速开始

1. 把整个 `zycg_board` 文件夹放到那台 24 小时开机的 Windows 电脑上（例如 `D:\zycg_board`）。
2. 双击 **`start.bat`**。
   - 首次启动会自动抓取最近约 14 天的公告（含下载 PDF，需几分钟），之后保持运行。
   - 看到窗口里出现 `内网访问: http://<IP>:8000` 即成功。
3. 用浏览器打开：
   - 本机：`http://127.0.0.1:8000`
   - 同一内网的手机 / 电脑：`http://<那台机器的内网IP>:8000`

> 手机访问：手机连到**与那台机器相同的 WiFi / 内网**，浏览器输入上面的内网地址即可。

## 二、24 小时自动运行（开机自启 + 崩溃自重启）

1. 双击 **`install_autostart.bat`**（建议右键"以管理员身份运行"，可多一层开机自启）。
   - 会创建一个"登录时启动"的快捷方式（最小化运行，无需管理员）。
   - 若以管理员运行，还会额外创建一个"系统启动"计划任务（更稳）。
2. `run_loop.bat` 自带崩溃自动重启（进程退出后 10 秒拉起）。
3. 完全不需要再手动管；机器一直开着，看板就一直可用。

停止 / 卸载：
- 停止服务：双击 `stop.bat`
- 取消开机自启：双击 `uninstall_autostart.bat`

## 三、功能

- **公告列表**：标题、采购公司、预算金额、发布日期、响应截止、品类、状态（进行中/已截止），按时间倒序，分页。
- **筛选**：关键词（标题/采购公司/品牌）、品类（服务器/网络/打印机/视频会议/存储/网络安全/计算机…）、品牌、状态、日期区间。
- **详情**：点任一公告 → 采购信息 + 品目需求明细表（品名/规格/品牌/型号/数量）+ 涉及品牌 + **下载询价通知书 PDF** + 打开央采原页。
- **实时刷新**：右上角 ↻ 可立即抓取最新公告；数据每 30 分钟自动更新。

## 四、配置（可选）

默认：端口 `8000`，每 `1800` 秒（30 分钟）抓取一次，首次种子近 `14` 天。

- **改端口**：把 `start.bat`、`run_loop.bat`、`stop.bat` 里的 `8000` 改成你要的端口（三处一致）。
- **改抓取间隔 / 种子天数**：在 `start.bat` 的 `python\python.exe server.py 8000` 前加环境变量，例如
  `set ZB_REFRESH=900`（15 分钟一次）、`set ZB_SEED_DAYS=30`（首抓 30 天）。
  也可在代码 `server.py` 顶部 `REFRESH_SECONDS / SEED_DAYS` 处直接改。

## 五、目录结构

```
zycg_board\
  python\        内置 Python 3.12（免安装，绿色）
  web\           前端（index.html / style.css / app.js）
  server.py      服务端 + 自动抓取线程
  fetcher.py     央采接口抓取（列表/详情/PDF）
  db.py          SQLite 数据层
  data\          运行后自动生成：board.db(数据库) + pdfs\(下载的PDF)
  start.bat / run_loop.bat / stop.bat
  install_autostart.bat / uninstall_autostart.bat
```

## 六、常见问题

- **防火墙弹窗**：首次运行 Windows 可能提示"允许访问网络"，请勾选**专用网络**并点"允许访问"（否则内网手机访问不到）。
- **手机打不开**：确认手机与机器在同一内网/WiFi；确认防火墙已允许；确认地址用的是机器的**内网 IP**（不是 127.0.0.1）。
- **端口被占用**：换端口（见"配置"）。
- **首次数据少/慢**：首次要抓 14 天并下载 PDF，需几分钟；之后每 30 分钟只增量抓新公告，很快。
- **想清数据重来**：停止服务后删除 `data` 文件夹，再 `start.bat` 会重新全量抓取。

## 七、数据来源与合规

- 数据来自中央政府采购网公开电子询价接口（`mkt.zycg.gov.cn`），仅**只读**抓取，不登录、不提交任何操作。
- 请合理设置抓取间隔（默认 30 分钟），避免过高频访问。
